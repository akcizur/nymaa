# Player character asset

**Asset:** Animated Human (low poly)  
**Author:** Quaternius  
**Source:** https://opengameart.org/content/animated-human-low-poly  
**License:** CC0 1.0 Universal (public domain)

The player model is a glTF Binary conversion of the CC0 Quaternius character. It contains the authored clips **Idle, Walk, Run, Jump, Punch, Death and Working**.
